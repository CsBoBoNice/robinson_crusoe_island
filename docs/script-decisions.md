## 二、全局性约定（由上述结论提炼）

1. **禁字幕**：日期、祸福表、战果统计等一律用**旁白或画面**表达。
2. **旁白优先**：内心独白、宗教反思、抒情段、神秘警告统一走旁白（后续提示词用独立 `<Audio N>`）。
3. **暴力尺度**：实拍真人风格下，食人/斩首/枪战用**中远景、侧写、遮挡、剪影**，不出血腥特写。
4. **资源经济**：同类物件用**一个模型 + 变体**（财宝、老公羊、叛乱水手等）。
5. **时间口径**：统一依 `docs/timeline-stages.md` 与 **D24**（阶段 9 = 第 26—27 年）；原著异文在旁白中可提。
